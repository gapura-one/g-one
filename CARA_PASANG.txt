G-ONE — Gapura One Network End-To-End (Prototype Tahap 1, data simulasi)
Paket aplikasi HP (PWA) untuk iPhone dan Android

1. HOSTING (sekali saja, oleh tim IT)
   Unggah seluruh isi folder ini (index.html, manifest.webmanifest, sw.js, folder icons)
   ke web server HTTPS, misalnya server internal perusahaan, GitHub Pages, atau Netlify.
   Wajib HTTPS agar bisa dipasang sebagai aplikasi dan dibuka offline.

2. PASANG DI iPHONE / iPAD
   Buka alamatnya di Safari > tombol Bagikan (kotak + panah ke atas) >
   Tambah ke Layar Utama > Tambah.

3. PASANG DI ANDROID
   Buka alamatnya di Chrome > muncul tawaran "Instal aplikasi" (atau menu ⋮ >
   Instal aplikasi / Tambahkan ke layar utama) > Instal.

4. LOGIN
   Akun demo ada di bawah kotak Sign in. Password semua akun: gone2026
